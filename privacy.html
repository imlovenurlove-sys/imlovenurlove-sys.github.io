개인정보처리방침

시행일: 2026년 11월 25일

1. 사용하는 Google 권한

  • youtube.upload: 운영자 본인의 채널에 동영상을 올리기 위해 사용합니다.
  • youtube.readonly: 승인 직후 어느 채널이 연결됐는지 확인하기 위해 채널 이름만 읽습니다.

2. 데이터 처리

  • Google 사용자 데이터는 운영자 본인의 컴퓨터 안에서만 처리되며, 외부 서버로 보내거나 제3자와 공유하지 않습니다.
  • 승인 토큰은 운영자 컴퓨터에 본인만 읽을 수 있는 파일로 저장됩니다.
  • 광고, 분석, 판매 목적으로 데이터를 쓰지 않습니다.
  • Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 접근 권한 철회

Google 계정 > 타사 연결에서 언제든지 이 앱의 접근 권한을 삭제할 수 있습니다. 삭제하면 컴퓨터에 남은 토큰도 더는 쓸 수 없습니다.

4. YouTube 서비스 약관

이 도구는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
